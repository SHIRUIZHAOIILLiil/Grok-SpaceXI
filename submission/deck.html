The problem

Every alert still needs a person.

  • Rules flag unusual money. Most flags have an ordinary explanation.
  • An analyst reads the profile, the transactions and the documents — then decides.
  • A wrong close is far worse than an unnecessary escalation.

How it decides

Numbers first, then documents, then IDs.

1 · Read the measurement

The alert carries structured values: £19,212.04, 30 days, Lebanon, limit £5,000.

2 · Find the money in a document

Search the customer's file for a document whose amount reconciles. No match, no close.

3 · Cite what decided it

Every verdict lists the document and transaction IDs it rests on, so it can be checked.

4 · Say the same thing twice

5 runs × 4 institutions, byte-identical. 4,000 cases in 5.5 seconds.

1:25 · 四个卡片快速带过，停在"byte-identical"上——这是 20% 的分。

Where the model is — and is not

The verdict is deterministic. The model reads prose.

  • 46 of 140 gift letters state a birth date in a sentence, not a field.
  • The model may return a verbatim quote; it must occur in the document, character for character.
  • Then the local parser reads it. A wrong quote changes nothing.

Measured on all 4,000 cases: the model changed 0 verdicts.
