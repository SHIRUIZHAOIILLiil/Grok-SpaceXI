Casefile closes transaction-monitoring alerts by reading the evidence, not by guessing. For each case it takes the alerts as measured facts and finds the documents on file that carry the same money: an invoice for the exact amount, a solicitor's letter naming the estate and the entitlement, a cash reconciliation listing the four deposits. It then returns CLOSE, RFI or ESCALATE with a reason code, a two-to-four sentence reason citing real amounts, dates and document IDs, and the evidence IDs it relied on. Four institutions run different policies — profile multiples, cash thresholds, beneficiary limits and which rules exist — so every threshold is read per institution, never as a global constant. The decision is a pure function of the case: Python standard library only, no network and no model in the decision path, byte-identical output across runs, and 4,000 cases in 5.5 seconds. A console shows the whole chain — alert, transactions, documents, verdict, reason — with every cited document one click away.
